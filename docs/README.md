# OctoAcme Project Management Docs

This README centralizes OctoAcme's project management process documents and provides a short summary of our processes to help new teammates and contributors get started.

## Quick summary

OctoAcme follows an iterative, customer-focused project management approach with clear roles and lightweight artifacts:

- **Initiation**: Capture problem, stakeholders, and success metrics with a Project One-pager.
- **Planning**: Create a prioritized backlog, define acceptance criteria and Definition of Done, estimate work, and map milestones.
- **Execution & Tracking**: Run regular standups, use a project board (Backlog → Ready → In Progress → In Review → QA → Done), keep a risk register, and require PRs with acceptance criteria.
- **Risks & Communication**: Maintain a risk register, use regular status updates, and follow escalation paths for blockers.
- **Release & Deployment**: Follow pre-release checks, automated pipelines, smoke tests, and rollback plans.
- **Retrospectives & Improvement**: Capture action items, track impact, and iterate on processes.

## How to use

Add updates to the individual doc files in `docs/` and, when appropriate, create a short PR referencing this README. Use the included issue template (`.github/ISSUE_TEMPLATE/add-update-content-to-process-docs.yml`) to request additions or changes to process docs.

## Key principles

The OctoAcme approach is built on these core principles:

- **Customer-first**: Prioritize customer value and usability.
- **Iterative delivery**: Deliver small, testable increments.
- **Clear ownership**: Each project has a named Project Manager and Product Lead.
- **Data-informed decisions**: Measure impact and iterate based on evidence.
- **Psychological safety**: Encourage feedback and learning.

## Getting started

1. **New to OctoAcme?** Start with the [Project Management Overview](octoacme-project-management-overview.md) to understand our approach and key roles.
2. **Starting a new project?** Follow the [Project Initiation Guide](octoacme-project-initiation.md) to kick off work properly.
3. **Managing a project?** Use the [Project Planning](octoacme-project-planning.md) and [Execution & Tracking](octoacme-execution-and-tracking.md) guides for day-to-day work.
4. **Preparing to release?** Check the [Release & Deployment](octoacme-release-and-deployment.md) guide for pre-release and deployment steps.
5. **Closing out?** Run a retrospective using the [Retrospective & Continuous Improvement](octoacme-retrospective-and-continuous-improvement.md) guide.
