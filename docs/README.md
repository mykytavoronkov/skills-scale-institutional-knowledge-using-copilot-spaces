# OctoAcme Project Management Docs

Welcome to the OctoAcme Project Management documentation. This folder contains all process documents that describe how OctoAcme plans, executes, and delivers projects.

## Overview

OctoAcme follows an iterative, customer-first approach to project management. Every project has a named Project Manager (PM) and Product Manager (PdM) who together drive delivery, outcomes, and stakeholder communication.

**Core principles:**
- **Customer-first** — prioritize customer value and usability in every decision.
- **Iterative delivery** — ship small, testable increments rather than big-bang releases.
- **Clear ownership** — each project has an accountable PM and Product Lead.
- **Data-informed decisions** — measure impact and iterate based on evidence.
- **Psychological safety** — encourage open feedback and continuous learning.

**Project lifecycle:**
1. **Initiation** — define the problem statement, align stakeholders, and establish a high-level timeline.
2. **Planning** — break work into a prioritized backlog, identify dependencies, set milestones, and agree on the Definition of Done.
3. **Execution** — build, test, review, and iterate in short sprints; track progress on the project board and escalate blockers early.
4. **Release** — deploy, verify, and announce the change; follow the deployment checklist and rollback plan.
5. **Close & Retrospective** — capture learnings, recognize the team, and feed action items back into future planning.

**Communication cadence:**
- Weekly sync: PM + PdM
- Twice-weekly standups for the delivery team
- Monthly stakeholder updates
- Ad-hoc escalations as needed
